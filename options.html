Wikidata Source Saver

Idle.

Copy a Wikidata item (Q42), open a page on a configured website and press the shortcut (Alt+Shift+A = this page only, Alt+Shift+X = stop; change them at chrome://extensions/shortcuts).

Extra terms (clipboard): the item first, then terms separated by commas, semicolons or new lines – several words per term are fine, and a language tag applies to the terms after it:
Q123, en: Pythagorean theorem, Pythagoras' theorem, it: teorema di Pitagora. Terms before any tag are used for every website; a website only receives terms in its own language(s) (set below). Wikidata labels and aliases are never used – only the page's own ID and the extras you type.

Use the website's own search engine

fills in a site: search, background-tab mode, “URL contains the term”, and a script that accepts cookies and reads up to 3 pages. Google may show a CAPTCHA if used a lot – the run then stops using it.

for wikis (ProofWiki, Encyclopedia of Mathematics…): a plain-request full-text search; “link text contains the term”, partial matches need your approval, redirects accepted. Adjust the path (/w/index.php or /index.php) if needed.

Steps: click button|link|tab|text "name" [exact] · collect · pages link "Page {n}" [max=10] (clicks Page 2, 3 … until none is left) · wait 1500 · each "A", "B" + indented lines ({x} = value) · # comments. Pasted Playwright lines like get_by_role("button", name="…") and get_by_text("…") also work as click steps. Limits per search (Safety & politeness): clicks and seconds.
The query is always the item's Wikidata label (never a guessed string). Results can be wrong, so searches always go through the review window.
Advanced

Site access

Chrome asks once (“read and change your data on all websites”) so you never get a permission prompt for a new website again. The extension still only contacts the websites you configured (and Wikidata, the Wayback Machine, search engines you set up). Without this, “Save all” asks for each website separately. Removing it keeps the individual websites you allowed earlier.

Website data file

Keep your websites in a JSON file on your computer (for example in a Nextcloud folder) instead of only inside the browser. The file becomes the source of truth; the browser keeps a copy that is used whenever Chrome has not (re)granted access to the file. Chrome may ask again after a restart – use “Re-grant access”.

Saving asks Chrome for permission to read the websites in your templates/search URLs (needed to check pages).
