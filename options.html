Wikidata Source Saver

Copy a Wikidata item (Q42 or its URL), open a page on a configured website and press the shortcut (or click the toolbar icon). It adds P1343: <website item> with qualifier P2699: <page URL> – or, if the website has its own Wikidata property (e.g. P2812 MathWorld ID), P2812: <ID> instead. If the site has a category and URL templates, the same term is also looked up on every other website in that category, and every page that exists is added too.

Extra terms: copy Q123, use of property, possession (item first, extra terms after, separated by commas or new lines) to also search those terms on all sites in the category – useful when a site uses several IDs for one item. Shortcut Alt+Shift+A saves only the current page. Change shortcuts at chrome://extensions/shortcuts.

Websites

Saving asks Chrome for permission to read the websites in your templates (needed to check whether a page exists). Template example: https://www.law.cornell.edu/wex/{id} and https://dictionary.nolo.com/{id}-term.html ({id} = the term; {first} = its first letter, e.g. https://www.investopedia.com/terms/{first}/{id}.asp; words are converted between sites using each site's separator and letter case).
